Capabilities

Magical CRUD Engine

Define your fields once; we handle the index, forms, validation, and state automatically with zero boilerplate.

01

Apply the Trait

Add the HasCrud trait to your Eloquent model to instantly unlock dashboard capabilities.

02

Configure Fields

Override the fields() method to define how your data should be displayed and validated.

03

Ship it

Your beautiful, responsive CRUD interface is ready. No controllers or views needed.

class Post extends Model 
{
    use HasCrud;

    public function fields() 
    {
        return [
            Field::make('title')->searchable(),
            Field::make('content')->textarea(),
            Field::make('status')->select([
                'draft' => 'Draft',
                'published' => 'Published'
            ])
        ];
    }
}

You can publish all dashboard views to your resources/views directory using php artisan vendor:publish --tag=tyro-dashboard-views. From there, you have complete control over the layout and components.
Yes. Simply set TYRO_DASHBOARD_PREFIX in your .env file. For example, TYRO_DASHBOARD_PREFIX=admin will move everything to /admin/*.
Absolutely. Tyro Dashboard uses standard shadcn CSS variables. You can even use tools like tweakcn.com to customize your theme visually and drop the variables right into your config.
By default, users with admin or super-admin roles have full access. You can easily customize this list in the config/tyro-dashboard.php file.
Yes! You can set your application name and logo via .env variables or directly in the configuration file to match your project's identity.
