Capabilities

Magical CRUD

Define fields once and generate full index, create, edit, and show flows automatically — with zero boilerplate.

01

Apply the Trait

Add the HasCrud trait to your Eloquent model to instantly unlock dashboard capabilities.

02

Configure Fields

Override the fields() method to define how your data should be displayed and validated.

03

Ship it

Your beautiful, responsive CRUD interface is ready. No controllers or views needed.

class Post extends Model 
{
    use HasCrud;

    public function fields() 
    {
        return [
            Field::make('title')->searchable(),
            Field::make('content')->textarea(),
            Field::make('status')->select([
                'draft' => 'Draft',
                'published' => 'Published'
            ])
        ];
    }
}

Onboarding

Up in Minutes.

A single command pulls in everything you need. No migration headaches, no manual configuration loops.

01

Install the Package

Pull in Tyro Dashboard via Composer. It automatically manages its core dependencies.

composer require hasinhayder/tyro-dashboard
02

Initialize

Run the interactive installer to set up your primary admin account and basic configuration.

php artisan tyro-dashboard:install
03

Go Live

Navigate to /dashboard and sign in. Your admin panel is ready to be populated.
