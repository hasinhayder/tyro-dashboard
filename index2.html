The "Magic" Trait

Just add HasCrud to your model. We handle the controller, routing, validation, views, and forms automatically.

1

Add Trait to Model

2

Define Fillables

3

Done. Admin Panel Ready.

class Product extends Model
{
    use HasCrud; // ⚡ The magic happens here

    protected $fillable = [
        'name',
        'price',
        'stock_status',
        'image'
    ];
}
